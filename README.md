# experiment-booking

Participant booking page for research experiments (Keio University, Inami Lab).

This page holds no data. It is opened as `?x=<deployment id>` and talks to that experiment's
Google Apps Script web app as an anonymous JSON API (credentials omitted), so it works for
people signed in to several Google accounts. All bookings are stored in the researcher's
Google Workspace (spreadsheet and calendar).

`index.html` is generated by `web/build_web.py` in the private source project; do not edit it here.
